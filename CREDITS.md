# Credits

Osaka Blue Glow was created by ruffryder007007 with assistance from OpenAI Codex.

The blue and cyan color palette is inspired by
[Azure Glow by Hydradevx](https://github.com/Hydradevx/omarchy-azure-glow-theme).
Thank you for the original color direction. This repository includes its own
configuration files and does not include Azure Glow's wallpaper or source prose.

The Japanese town wallpaper was generated with OpenAI image generation for this
theme. The animation was made from that artwork with the included C++ renderer
and FFmpeg. Its effects are procedural: mountain mist, clouds, two dimming
windows, and a sputtering street lamp with a synchronized street reflection.

The icon preference selects the separately installed Yaru-blue icon theme;
no icon artwork is bundled here.
